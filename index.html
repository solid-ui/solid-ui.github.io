Two approaches, same goal: render an RDF resource as an editable form based on its type. These demos show both the UI Ontology approach (used by SolidOS) and the SHACL approach.

Each demo links a class (e.g. schema:Person) to a form definition. The pane reads the resource's @type, finds the matching form, and renders it. Edits flow back to the data via a LOSOS-style reactive store.
